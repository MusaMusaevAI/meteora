# Volant — план развития (записано 28.10.2026)

## 1. Навигация и история
- [ ] Возврат на стартовый экран: кнопка «← Назад / Новая запись», ⌘W закрывает запись, а не приложение.
- [ ] «Журнал встреч»: история всех расшифровок (поиск, открыть, удалить), стартовый экран со списком последних.

## 2. Входные форматы — «полноценный аналог MacWhisper»
- [ ] Аудио: MP3, M4A/AAC, WAV, AIFF, FLAC, CAF, OGG/Opus, WebM-аудио.
- [ ] Видео: MP4, MOV, M4V, MKV, WebM; перетаскивание любых этих файлов.

## 3. Экспорт расшифровки
- [ ] Word (.docx) со скриншотами ключевых кадров внутри текста; также PDF, RTF, HTML, ODT, TXT, SRT, VTT, Markdown, JSON.
- [ ] Переключатель таймкодов: «без времени / у абзацев / у каждой фразы» (экономия токенов для нейросетей).
- [ ] Склейка фраз в абзацы (по паузам), чтобы текст читался как разговор.

## 4. Итоги встречи (маленькая локальная модель)
- [ ] После расшифровки — краткое резюме встречи и автоназвание.
- [ ] Название = суть встречи + дата/время: из имени файла Телемоста («…26.10.26 13-59-23»), иначе из метаданных, иначе — время расшифровки.
- [ ] Выбор модели: Apple Foundation Models (если поддерживает русский) или компактная открытая LLM, скачиваемая по кнопке с проверкой хешей.

## 5. Запись встреч прямо в Volant
- [ ] Источники: микрофон, системный звук (созвоны в наушниках), оба сразу; выбор устройства.
- [ ] Экономичный формат: Opus (≈ 10–15 МБ/час речи) с качеством, достаточным для распознавания; опция AAC.
- [ ] Индикатор записи, пауза, автозапуск расшифровки после остановки.

## 6. Автоматизация
- [ ] Наблюдение за папкой (по умолчанию «Документы/Телемост»): новый файл → автоматическая расшифровка.
- [ ] Работа в фоне (значок в строке меню), системное уведомление «Расшифровка готова».

## 7. Обновления
- [ ] Кнопка «Проверить обновления»: смотрит релизы на GitHub, скачивает новую версию, проверяет подпись и предлагает установить с перезапуском.
- [ ] Для этого: публичное место для релизов (приватный репозиторий коллеги скачать не смогут) и ключ подписи обновлений в секретах GitHub.

## 8. Настройки
- [ ] Окно настроек с тумблерами для всех опций: таймкоды, абзацы, автоназвание, итоги, наблюдение за папкой, уведомления, качество записи, формат экспорта по умолчанию.

## 9. iPhone (обсуждается)
- [ ] Версия для iOS 27 с той же расшифровкой; установка через Xcode с бесплатным Apple ID (продление раз в 7 дней).
