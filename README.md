# Meteora

Слова на встрече пролетают, как метеоры. Meteora их ловит: превращает запись в текст, кадры и звук, с которыми можно работать дальше.

Лёгкое приложение для macOS, которое открывает записи встреч из Яндекс Телемоста (`.webm`) и других программ и превращает их в то, с чем можно работать дальше:

- **посмотреть или послушать** запись: плеер с волной громкости вместо обычной полосы, поэтому сразу видно, где говорят;
- **звук для расшифровки** в высоком или среднем качестве (M4A) с выравниванием громкости;
- **Расшифровка прямо на Mac** (⌘T): открытая модель Сбера GigaAM-v3 превращает русскую речь в текст с пунктуацией. Кнопка «Научить Meteora слушать» один раз скачивает модель (232 МБ). Расшифровка показывается рядом с видео: щелчок по времени переходит к нужному месту. Текст можно читать абзацами (фразы склеиваются по паузам) или по фразам;
- **передать звук в другое приложение** (⌘⇧M, меню «Запись»): звук сохраняется в «Загрузки/Meteora», файл копируется в буфер обмена и открывается в установленном приложении для расшифровки;
- **экспорт** (⌘E): Word со скриншотами кадров, PDF, RTF, HTML, Markdown, TXT, субтитры SRT и WebVTT, CSV, JSON — несколько форматов за раз. Время в тексте: без него, у абзацев или у каждой фразы;
- **журнал встреч**: на стартовом экране — все открытые записи с поиском по названиям и тексту расшифровок. Окно устроено как в чат-приложениях: слева — все записи с поиском, в центре — плеер и под ним текст, справа — параметры; боковые панели и панель текста можно скрыть или потянуть за край. «Убрать из списка» удаляет только расшифровку, сам файл остаётся на месте;
- **говорящие**: «Разделить по говорящим» помечает реплики «Спикер 1, 2…»; имена меняются в боковой панели и сразу попадают в экспорт;
- **итоги встречи**: краткое содержание, главное, решения и задачи. На выбор — модель на этом Mac (лёгкая 0,6 ГБ, средняя 1,4 ГБ или сильная 2,7 ГБ, семейство Qwen3.5) или облачная по своему ключу API: Claude, OpenAI, Gemini или любой сервис, совместимый с OpenAI. Ключ хранится в связке ключей; текст уходит провайдеру только по нажатию «Подвести итоги» и после одного подтверждения. Название из итогов можно сделать названием встречи;
- **словарь** (⌘⇧D): как писать аббревиатуры и названия (ПДС, ОПС, Газфонд…). Произнесённое по буквам («пэдээс») распознаётся само; термины словаря ещё и подсказываются модели во время расшифровки (hotwords, настройка «asr.hints», по умолчанию включена; чуть медленнее); словарь можно загрузить и выгрузить в CSV;
- **запись встречи** (⌘⇧R): микрофон, звук Mac или оба сразу — в экономный Opus. Микрофон любой: встроенный, AirPods, USB или iPhone рядом. В строке меню видны время и пауза; после остановки запись открывается и расшифровывается сама;
- **пакетная обработка** (⌘⇧B, или выбрать сразу несколько файлов): записи расшифровываются по очереди и сохраняются в выбранных форматах в одну папку;
- **ключевые кадры**: снимки экрана в моменты смены картинки (слайды, отчёты, интерфейсы) с распознанным текстом. Сохраняются в PDF с поиском, в папку Markdown + PNG или копируются текстом, чтобы вставить в Claude рядом с расшифровкой.

Всё обрабатывается на самом Mac. В интернет Meteora выходит только по нажатию кнопки — чтобы один раз скачать модели: распознавания речи, различения голосов и языковую модель для итогов. Если для итогов выбран облачный провайдер, текст расшифровки отправляется ему по вашему ключу. Перед отправкой ФИО, телефоны, e-mail, паспорт, СНИЛС, ИНН, карты и счета заменяются метками прямо на Mac (правила Cloud.ru Guardrails, переключатель в настройках итогов) и подставляются обратно в готовые итоги. Каждый файл модели сверяется с закреплённой контрольной суммой.

При первом запуске открывается короткое знакомство с приложением (его можно пропустить и открыть снова: «Справка → Знакомство с Meteora»). Прямо в нём можно скачать модель речи.

**Форматы.**
- Сама macOS: MP4, MOV, M4V, M4A, M4B, MP3, WAV, AIFF, CAF, AAC, ALAC, FLAC, AC3/EAC3, 3GP, AU; WebM разбирает собственный парсер Meteora.
- Через изолированный конвертер: MKV, MKA, AVI, WMV, WMA, ASF, FLV, MPEG/MPG, VOB, TS/MTS/M2TS, OGV, OGG (Vorbis/Opus), OPUS, OGA, AMR, 3GA. Такие файлы сначала преобразуются в MP4 (H.264 + AAC) или M4A (AAC 160 кбит/с) во временную папку. Это делает FFmpeg в отдельном процессе без сети и без доступа к другим файлам (подробнее в [SECURITY.md](SECURITY.md), п. 9).

**Хранилище** (⌘, или кнопка внизу боковой панели) показывает, что Meteora держит на диске: модель, сохранённые расшифровки, звук в «Загрузки/Meteora», временные файлы. Ненужное отмечается галочками и удаляется.

## Установка

1. Откройте `Meteora.dmg` и перетащите Meteora в «Программы».
2. При первом запуске macOS предупредит о неизвестном разработчике (приложение подписано без платного сертификата Apple). Нажмите «Готово», затем откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**. Это нужно один раз.

Требуется macOS 14 или новее, на Apple Silicon или Intel.

## Дизайн

Перламутровый фон и гунметал в тёмной теме, стальной синий акцент, видео на «тёмном металле». Перелив перламутра (по мотивам флаконов Amouage Portrayal и Reflection 45) появляется только в знаке, иконке, знакомстве и индикаторах обработки. Анимации знакомства собраны в Remotion: `motion/onboarding` (`npm i`, затем `npx remotion studio`); готовые ролики лежат в `Resources/Onboarding`.

**Без открытия приложения.** В Finder: правый клик по записи → «Службы» → «Meteora: передать звук». На эту службу можно назначить глобальное сочетание клавиш: Системные настройки → Клавиатура → Сочетания клавиш → Службы.

## Как устроено

- `Sources/MeteoraCore`: строгий разборщик WebM/Matroska, декодирование Opus системным декодером Apple (AudioToolbox), экспорт AAC, выбор кадров по структуре видеопотока (ключевые кадры и резкие изменения), распознавание текста через Apple Vision, экспорт PDF и Markdown.
- Ключевые кадры декодируются напрямую через WebCodecs: приложение берёт сжатые кадры из файла и передаёт их системному декодеру WebKit. Плеер при этом не перематывается, смотреть запись можно во время анализа, а кадры получаются в полном разрешении записи. 10 минут видео 1920×1200 обрабатываются примерно за 8 секунд.
- `Sources/Meteora`: интерфейс на SwiftUI. Видео показывает WebKit через собственную схему `meteora-media://`: она отдаёт ровно два ресурса, страницу плеера и открытый файл.
- `Sources/MeteoraASR`: расшифровка. Детектор речи Silero VAD (входит в приложение) режет звук на фразы, GigaAM-v3 e2e RNN-T распознаёт каждую. Движок — sherpa-onnx и ONNX Runtime, они статически собраны в приложение. Модель скачивается по требованию; её хеши закреплены в коде.
- `Sources/MeteoraLLM`: резюме и заголовок встречи на самом Mac — открытая модель Qwen3.5-4B (Apache-2.0, 2,7 ГБ, скачивается по требованию, SHA-256 закреплён в коде) на движке llama.cpp, статически собранном из закреплённых исходников (`scripts/build_llama.sh`); длинные встречи обрабатываются по частям (map-reduce).
- `Sources/MeteoraConverter`: XPC-служба `com.musamusaev.meteora.converter` для редких форматов. Запускает встроенный `ffmpeg` (LGPL, минимальная сборка из `scripts/build_ffmpeg.sh`) в собственной песочнице без прав; приложение передаёт ей только два файловых дескриптора. Клиент в приложении — `Sources/Meteora/MediaConverter.swift`, общий протокол — `Sources/MeteoraConverterProtocol`.
- Сторонние компоненты и лицензии перечислены в `Resources/THIRD_PARTY_NOTICES.txt`.
- Безопасность описана в [SECURITY.md](SECURITY.md).

## Сборка

DMG собирает GitHub Actions на macOS (`.github/workflows/build.yml`): модульные тесты, сборка FFmpeg из закреплённых исходников (результат кэшируется), сборка универсального бинарника, подпись с hardened runtime и песочницей, самотест настоящего приложения на тестовых записях, упаковка в DMG. Результат лежит в ветке `build-output`.

Локально, на Mac с Xcode 26:

```bash
swift test
scripts/build_app.sh && scripts/make_dmg.sh
```
