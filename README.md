# Volant

*Verba volant, scripta manent.* Слова улетают, написанное остаётся.

Лёгкое приложение для macOS, которое открывает записи встреч из Яндекс Телемоста (`.webm`) и превращает их в то, с чем можно работать дальше:

- **посмотреть или послушать** запись: плеер с волной громкости вместо обычной полосы, поэтому сразу видно, где говорят;
- **звук для расшифровки** в высоком или среднем качестве (M4A) с выравниванием громкости;
- **«Отправить в MacWhisper»** (⌘⇧M): звук сохраняется в «Загрузки/Volant», файл копируется в буфер обмена и сразу открывается в MacWhisper;
- **ключевые кадры**: снимки экрана в моменты смены картинки (слайды, отчёты, интерфейсы) с распознанным текстом. Сохраняются в PDF с поиском, в папку Markdown + PNG или копируются текстом, чтобы вставить в Claude рядом с расшифровкой.

Всё обрабатывается на самом Mac. В приложении нет сетевого доступа: он не запрошен в правах песочницы.

## Установка

1. Откройте `Volant.dmg` и перетащите Volant в «Программы».
2. При первом запуске macOS предупредит о неизвестном разработчике (приложение подписано без платного сертификата Apple). Нажмите «Готово», затем откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**. Это нужно один раз.

Требуется macOS 14 или новее, на Apple Silicon или Intel.

## Быстрые клавиши

| | |
|---|---|
| Пробел | воспроизведение / пауза |
| ← / → | на 5 секунд назад / вперёд |
| ⌘O | открыть запись |
| ⌘S | сохранить звук как… |
| ⌘⇧M | отправить звук в MacWhisper |
| ⌘K | найти ключевые кадры |
| ⌘⇧E | сохранить кадры в PDF |
| ⌘⇧C | скопировать текст кадров |

**Без открытия приложения.** В Finder: правый клик по `.webm` → «Службы» → «Volant: звук в MacWhisper». На эту службу можно назначить глобальное сочетание клавиш: Системные настройки → Клавиатура → Сочетания клавиш → Службы.

## Как устроено

- `Sources/VolantCore`: строгий разборщик WebM/Matroska, декодирование Opus системным декодером Apple (AudioToolbox), экспорт AAC, выбор кадров по структуре видеопотока (ключевые кадры и резкие изменения), распознавание текста через Apple Vision, экспорт PDF и Markdown.
- `Sources/Volant`: интерфейс на SwiftUI. Видео показывает WebKit через собственную схему `volant-media://`: она отдаёт ровно два ресурса, страницу плеера и открытый файл.
- Безопасность описана в [SECURITY.md](SECURITY.md).

## Сборка

DMG собирает GitHub Actions на macOS (`.github/workflows/build.yml`): модульные тесты, сборка универсального бинарника, подпись с hardened runtime и песочницей, самотест настоящего приложения на тестовых записях, упаковка в DMG. Результат лежит в ветке `build-output`.

Локально, на Mac с Xcode 26:

```bash
swift test
scripts/build_app.sh && scripts/make_dmg.sh
```
